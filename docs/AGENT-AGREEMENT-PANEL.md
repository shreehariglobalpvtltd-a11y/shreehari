## २. एजेन्ट प्यानल — `agent-panel.html`

पहिलो पटक खोल्दा एजेन्ट ID, नाम, मोबाइल, रुट, प्रति टिकट कमिसन र
स्टाफको WhatsApp नम्बर भरेर आफ्नो पासवर्ड बनाउनुहोस्।

- टिकट काटेपछि **नयाँ टिकट दर्ता** मा भर्नुहोस् (PNR आफैँ बन्छ)।
- माथिका कार्डमा देखिन्छ: आजका टिकट · यो महिना · कुल कमिसन · **बुझाउन बाँकी रकम**।
- दिनको अन्त्यमा **📱 आजको रिपोर्ट WhatsApp** — स्टाफकहाँ आजको पूरा हिसाब जान्छ।
- **📄 CSV** ले Excel मा खोल्न मिल्ने फाइल दिन्छ। **💾 ब्याकअप** हप्तामा एकपटक गर्नुहोस्।
- रद्द टिकटको कमिसन आफैँ घट्छ (सम्झौता खण्ड ३, बुँदा ४ अनुसार)।

### ⚠ सुरक्षाबारे इमानदार कुरा

प्यानलको लगइन **यही फोन/कम्प्युटरको ताला मात्र** हो। पासवर्ड कुनै server मा
जाँदैन — यही यन्त्रमा (ह्यास गरेर) बस्छ। त्यसैले:

- यसले अरूलाई अलिकति रोक्छ, तर **साँचो सुरक्षा होइन**।
- हरेक एजेन्टको डाटा उसकै यन्त्रमा छुट्टै बस्छ — **कम्पनीले यहाँबाट सबै एजेन्टको
  हिसाब एकै ठाउँ हेर्न पाउँदैन**।
- ब्राउजरको डाटा मेटे टिकट पनि जान्छ — त्यसैले ब्याकअप जरुरी छ।

सम्झौताको **खण्ड ३, बुँदा ८** अनुसार पनि — टिकट र कमिसनको **अन्तिम प्रमाण
कम्पनीको सर्भरको रेकर्ड** हो, यो प्यानलको हिसाब होइन। यो मिलाउन र
सम्झाउनका लागि मात्र हो।

## अबको बाटो — साँचो प्रणाली चाहिँदा

तलका कुरा **static HTML ले कहिल्यै दिन सक्दैन**; यिनका लागि server चाहिन्छ:

| चाहिएको कुरा | किन अहिले हुँदैन | के चाहिन्छ |
|---|---|---|
| साँचो लगइन (पासवर्ड server मा) | पासवर्ड यन्त्रमै बस्छ | PHP + MySQL, वा Firebase / Supabase |
| कम्पनीले सबै एजेन्टको हिसाब एकै ठाउँ | डाटा एजेन्टकै यन्त्रमा | साझा database |
| टिकट आफैँ गनिने, कमिसन आफैँ जोडिने | हातले दर्ता गर्नुपर्छ | बुकिङ प्रणाली + API |
| स्वतः WhatsApp सन्देश (chat bot) | अहिले बटन थिच्नुपर्छ | WhatsApp Business API |
| अनलाइन भुक्तानी | — | Payment gateway (eSewa / Khalti / Razorpay) |

Hostinger को shared hosting मा **PHP + MySQL** पहिल्यै आउँछ — त्यसैले पहिलो
पाइला त्यहीँबाट सुरु गर्न सकिन्छ। अहिलेको दुवै पाना त्यो बन्नुअघि दिनदिनैको
काम चलाउन बनाइएका हुन्, र पछि पनि **अफलाइन backup** का रूपमा काम लाग्नेछन्।

## प्राविधिक टिपोट (developer का लागि)

- **Vanilla HTML/CSS/JS** मात्र। कुनै build step छैन। ES2017+।
- भण्डारण: `localStorage` + `.json` download/upload।
- बाहिरका पुस्तकालय (cdnjs, सबै `defer`, नआए पनि पाना चल्छ):
  `signature_pad` · `qrcodejs` · `html2canvas` · `jspdf`
  `defer` भएकाले तिनी inline script पछि आउँछन् — त्यसैले पुस्तकालय
  आइसकेपछि `lateInit()` ले हस्ताक्षर प्याड र QR फेरि जोड्छ।
- रङ token हरू `:root` मा; dark mode `prefers-color-scheme` + `[data-theme]` दुवैले।
- **`color-mix()` प्रयोग नगर्नुहोस्** — `html2canvas` 1.4.1 ले बुझ्दैन र PDF भाँचिन्छ।
- सम्झौताको print CSS ५ पानामै अट्ने गरी मिलाइएको छ। नयाँ खण्ड थपे
  हरेक `.sheet` को उचाइ फेरि जाँच्नुहोस् (297mm भन्दा कम हुनुपर्छ)।
- क्याल्कुलेटर प्रिन्टमा देखिँदैन — कानुनी अंग होइन।
