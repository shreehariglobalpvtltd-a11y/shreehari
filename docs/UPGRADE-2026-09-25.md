## 7. AI Manager — "Shree Hari ko manager"

Char kura, char switch, sabai OFF:

**a) Sammjhana (`ai_memory_on`).** Sahayak le manche sammjhcha: kati patak
gaye, kaha bata chadhne gardachan, kun disa, kun bhasa ma likhchan, aakhiri
yatra kahile. Number **kahile pani sidhai rakhdaina** — hash garera rakhcha,
ra manche le "mero data hatau" bhanyo bhane Admin → AI Manager → Memory bata
ek tap ma hatincha. Yo sammjhana booking, payment, cancel ko event bata aafai
lekhincha — kunai extra kam chaindaina.

**b) Sikaai (`ai_examples_on`).** Sahayak le galat jawaf dio bhane customer le
👎 thicna sakcha, ya "galat" / "hoina" lekhna sakcha. Tyo office ko list ma
jancha. Office le **thik jawaf lekhera approve garepachi matra** Sahayak le
tyo tarika sikcha. Approve na garda samma kehi sikdaina — yo jaanikai, jasle
customer le sikaayera Sahayak bigrna sakdaina.

**c) Office copilot.** Admin → AI Manager → Copilot ma office le aafnai bhasa
ma sodhna sakcha ("aaja kati seat bachyo?", "Ram ko ticket cancel garna milcha?").

**d) Marketing ra social (`social_publish_on`).** Facebook Page, Instagram ra
Telegram ko lagi post: office le topic lekhcha, AI le teen bhasa ma caption
banaucha (fare **settings bata** — aafai price banaudaina), office le approve
garcha, ra cron le pathaucha. Din ma kati post bhanne cap cha (`social_daily_cap`,
default 6). Approve na bhaye kehi pathaidaina.

**e) Raat ko refresh (`ai_refresh_on`).** Raat 2:20 baje company ko fact
(route, pickup, fare, refund) knowledge base ma pheri lekhincha, ra purano
sammjhana safa hunecha — Sahayak ra knowledge base kahile pani farak kura
bhandainan.

Post pathauna Facebook / Instagram / Telegram ko token pani halnu parcha:
`meta_page_id`, `meta_page_token`, `ig_user_id`, `telegram_bot_token`,
`telegram_channel`. Khali chodyo bhane tyo channel off rahancha.

`includes/aimemory.php`, `includes/ailearn.php`, `includes/socialposts.php`,
`admin/ai-manager.php`, `cron/ai-refresh.php`, `cron/social-publish.php`

## 9. App chitto khulyo (switch: `bundle_assets_on`)

Pahila phone le 14 ta JavaScript file ra 2 ta CSS file — 16 request, 1.4 MB —
tanne parthyo. Aba ek JS ra ek CSS: **1002 KB → 614 KB** (13 request kam),
CSS **442 KB → 354 KB**. gzip pachi ajhai sano.

Yo file `tools/build.mjs` le banaucha ra repository ma commit huncha, tyesaile
server ma build garnu pardaina — git pull matra.

**Suraksha jaal:** template ma naya script thapyo ra build garnu bhulyo bhane,
ya build purano bhayo bhane, app aafai purano 16 file ma farkincha ra log ma
lekhcha. Purano code chalne sambhavana **shunya** — yehi ek galti bahira bata
dekhiँdaina, tyesaile dobar jaanch cha (serve time ma mtime, CI ma sha256).

Script badlepachi: `node tools/build.mjs` chalaunu, ra `sw.js` ko `ASSET_VER`
badalnu. CI aafai janchcha (`node tools/build.mjs --check`).

`tools/build.mjs`, `includes/assetbundle.php`, `tests/bundle-test.php`

## 11. Deploy — VPS ma ek command

`deploy/vps-pull-deploy.sh`. VPS ma site ko folder bata:

```bash
cd /var/www/shreehariglobal.in/public_html
sudo bash deploy/vps-pull-deploy.sh --dry-run    # pahila k huncha herne
sudo bash deploy/vps-pull-deploy.sh              # deploy
sudo bash deploy/vps-pull-deploy.sh --rollback   # bigrio bhane pachadi
```

Kram: backup (tarball + database dump) → git fast-forward → badlieko PHP file
ko `php -l` → baki migration (mysql client bata, `schema_migrations` ma record)
→ `chown www-data` → PHP-FPM ra nginx reload → site 200 ra `/api/config.php`
JSON cha ki jaanch. Site 200 aaena bhane **aafai purano commit ma farkincha**.

Database ko password kahile pani command line ma jaँdaina (ps ma dekhinne
hunthyo) ra kahile pani print huँdaina — 600 permission ko my.cnf ma lekhincha
ra kam sakepachi mitincha.

**Yo script ahile samma kunai server ma chalaieko chaina.** Pahilo patak
`--dry-run` bata suru garnu.
